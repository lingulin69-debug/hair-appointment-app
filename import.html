AMY.SALON ONE-TIME RESTORE

備份匯入工具

這個頁面只給 PC 端一次性使用。先上傳剛剛救回來的備份 JSON，確認筆數後，再按一次把資料回寫到 Firebase。 這個工具只會 upsert 備份裡的資料，不會主動刪除雲端現有資料。

尚未載入備份。 先選擇 JSON 檔或貼上備份內容，再按「讀取備份」。

登入與權限

尚未登入。 匯入工具現在需要先登入。只有管理員可以把資料回寫到 Firebase。
權限規則
  • 第一個登入並完成 bootstrap 的帳號會成為管理員。
  • owner 可以進主系統後台，但不能操作這個匯入頁。
  • 這個匯入工具只開給管理員，staff 與 owner 都不可執行匯入。

第一步：載入備份

匯入規則
  • 優先使用 localStorage.merged 的資料。
  • 如果某個集合 localStorage.merged 為空，才退回使用 firestoreCache。
  • 同一個 ID 若出現重複，只保留一份。
這一版會回寫
  • clients
  • appointments
  • leaves
  • storeItems
