AMY.SALON ONE-TIME RESTORE

備份匯入工具

這個頁面只給 PC 端一次性使用。先上傳剛剛救回來的備份 JSON，確認筆數後，再按一次把資料回寫到 Firebase。 這個工具只會 upsert 備份裡的資料，不會主動刪除雲端現有資料。

尚未載入備份。 先選擇 JSON 檔或貼上備份內容，再按「讀取備份」。

  • 如果某個集合 localStorage.merged 為空，才退回使用 firestoreCache。
  • 同一個 ID 若出現重複，只保留一份。
